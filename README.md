# Oyun Defteri

Matematik ve fen konuları için sınıfta ya da evde oynanan etkileşimli oyunlar. Hepsi tek bir sitede, aynı görünümde ve tek bir başlık çubuğuyla toplanıyor: sol üstteki menüden istediğin oyuna geçebilir, oklarla sıradakine ilerleyebilirsin. Açık mod kareli defter, koyu mod kara tahta görünümündedir.

> Durum: oyunlar ortak temaya taşınıyor. Orijinal dosyalar `mustafa-htmls/` klasöründe değiştirilmeden duruyor.
